# Demographic Analysis

## Objectives
- Examine execution counts by gender
- Examine execution counts by race
- Calculate average age at execution

## SQL Techniques Used
- Aggregation (`COUNT`, `GROUP BY`)
- Aggregation with averages (`AVG`)

## Findings
- **Gender**: The dataset shows an overwhelmingly male population on death row.
- **Race**: Black and Hispanic inmates are disproportionately represented compared to Texas demographics.
- **Age**: The average age at execution is approximately late 30s.
