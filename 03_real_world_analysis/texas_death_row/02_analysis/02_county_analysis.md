# County Analysis

## Objectives
- Identify counties with the highest number of executions
- Rank counties by execution count

## SQL Techniques Used
- Aggregation (`COUNT`, `GROUP BY`)
- Window function (`RANK`)

## Findings
- Harris County consistently leads executions, far surpassing other counties.
- Several smaller counties show fewer executions but still contribute to overall totals.
- Ranking queries confirm Harris County as #1, with Dallas and Tarrant counties also prominent.
