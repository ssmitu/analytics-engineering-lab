# SQL Foundations

This section documents my foundational SQL learning journey through structured practice and reasoning-based notes.

The goal of this phase was not only to learn SQL syntax, but also to understand how queries are used to:
- retrieve and filter data
- work with relational tables
- calculate and summarize information
- modify database records
- manage database structures

Each topic folder contains:
- `examples.sql` → selected practice queries
- `notes.md` → reasoning, thought process, and key learnings

---

## Topics Covered

### 1. SELECT & WHERE
Basic querying, filtering, sorting, limiting, and pattern matching.

### 2. JOIN Basics
Understanding relationships between tables using `INNER JOIN` and `LEFT JOIN`.

### 3. SQL Expressions
Using calculated fields and expressions to transform raw data into meaningful outputs.

### 4. Aggregations
Applying functions like `AVG()`, `SUM()`, `COUNT()`, `GROUP BY`, and `HAVING` for summarized analysis.

### 5. Data Modification & Schema Operations
Working with:
- `INSERT`
- `UPDATE`
- `DELETE`
- `CREATE TABLE`
- `ALTER TABLE`
- `DROP TABLE`

---

## Key Learning Focus

Throughout this section, I focused on:
- understanding query logic instead of memorizing syntax
- translating real-world problems into SQL operations
- building strong relational database fundamentals
- documenting reasoning behind each solution
